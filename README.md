# भाजीपाला घाऊक व्यापारी बिलिंग प्रणाली (Vegetable Wholesaler Mobile Billing App)

भाजी मंडईतील अडते, घाऊक भाजीपाला व्यापारी आणि शेतकरी उत्पादक कंपन्यांसाठी विकसित केलेली **संपूर्ण मराठी मोबाईल बिलिंग ऍप्लिकेशन**.

---

## 🌟 मुख्य वैशिष्ट्ये (Key Features)

1. **अस्सल मराठी युझर इंटरफेस (100% Marathi UI)**:
   - ऍपमधील सर्व बटणे, लेबल्स, इनपुट फॉर्म्स, याद्या, हिशोब आणि PDF पावत्या शुद्ध आणि सोप्या मराठी भाषेत आहेत (उदा. 'ग्राहक नाव', 'दर', 'प्रमाण', 'एकूण रक्कम', 'व्हेंडर नाव', 'हमाली/वाहतूक खर्च', 'अंतिम देय रक्कम').

2. **व्हेंडर व्यवस्थापन (Vendor / Farmer Management)**:
   - भाजीपाला पुरवठादार किंवा शेतकऱ्यांची नोंद (नाव, मोबाइल नंबर, मार्केट यार्ड पत्ता/गाव आणि शेरा).
   - व्हेंडर माहिती अद्ययावत (Edit) करणे आणि हटवणे (Delete).
   - एका क्लिकवर व्हेंडरला थेट फोन कॉल लावण्याची सुविधा.

3. **गतिमान बिलिंग प्रणाली (Dynamic Billing with Multi-Vendor Support)**:
   - ग्राहकाचे नाव, मोबाइल नंबर, दिनांक आणि देयक प्रकार (रोख / उधारी / ऑनलाइन UPI).
   - **एकाच बिलात विविध व्हेंडर्सची निवड**: बिलामधील प्रत्येक भाजी कोणत्या व्हेंडर किंवा शेतकऱ्याकडून आली हे ड्रॉपडाऊनमधून निवडता येते (उदा. बटाटा - 'आनंद भाजी मंडई', टोमॅटो - 'पाटील फार्म्स').
   - कांदा, बटाटा, टोमॅटो, लसूण इत्यादी भाज्यांचे जलद निवडीसाठी क्विक-चिप्स.
   - प्रमाण (किलो, क्विंटल, पोते, क्रेट, जुडी) आणि दर टाकल्यास एकूण रक्कम **आपोआप (Auto-calculated)** होते.
   - हमाली / वाहतूक खर्च (+) आणि सूट / कपात (-) जोडून अंतिम देय रक्कम थेट मोजली जाते.

4. **मराठी PDF बिल निर्मिती (Professional Marathi PDF Invoice)**:
   - `ReportLab` आणि गुगलच्या `Noto Sans Devanagari` फॉन्टचा वापर करून सुंदर A4 आकाराचे बिल तयार होते.
   - बिलावर "।। श्री गणेशाय नमः ।।", व्यापाऱ्याचे नाव, पत्ता, संपर्क, ग्राहक तपशील, व्हेंडर नावांसह मालाचा तक्ता, हिशोब सारांश, नियम व अटी आणि अधिकृत स्वाक्षरी/शिक्का असतो.

5. **WhatsApp वर १-क्लिक शेअरिंग (Instant WhatsApp Sharing)**:
   - बिलाचा संपूर्ण तपशील मराठीमध्ये सुंदर फॉरमॅट करून थेट ग्राहकाच्या WhatsApp वर पाठवण्यासाठी "WhatsApp वर पाठवा" बटण उपलब्ध.

## 🛠 तंत्रज्ञान रचना (Tech Stack)

| घटक | तंत्रज्ञान | तपशील |
| :--- | :--- | :--- |
| **Frontend** | React Native (Expo) | Android, iOS आणि Web साठी क्रॉस-प्लॅटफॉर्म मोबाईल ऍप |

## 🚀 स्थानिक पातळीवर ऍप सुरू करण्याचे टप्पे (Local Setup Guide)

### पायरी १: बॅकएंड सर्व्हर सुरू करणे (Python FastAPI)

१. कमांड प्रॉम्प्ट किंवा पॉवरशेल उघडून बॅकएंड डिरेक्टरीमध्ये जा:
```bash
cd "c:\Antigravity Project\BillingApp\backend"
```

२. आवश्यक पायथन पॅकेजेस इन्स्टॉल करा:
```bash
pip install -r requirements.txt
```

३. बॅकएंड सर्व्हर सुरू करा:
```bash
python run.py
```
- सर्व्हर सुरू होईल: `http://localhost:5000`
- स्वयंचलित API दस्तऐवजीकरण (Swagger Docs): `http://localhost:5000/docs`
*(टीप: पहिल्यांदा सर्व्हर सुरू होताच ५ नामांकित भाजीपाला व्हेंडर्स आणि १ नमुना बिल आपोआप डेटाबेसमध्ये तयार होते.)*

---

### पायरी २: मोबाईल ऍप सुरू करणे (React Native Frontend)

१. नवीन टर्मिनल विंडो उघडा आणि `frontend` डिरेक्टरीमध्ये जा:
```bash
cd "c:\Antigravity Project\BillingApp\frontend"
```

२. डिपेन्डन्सी इन्स्टॉल करा:
```bash
npm install
```

३. ऍप्लिकेशन सुरू करा:
```bash
npx expo start
```

४. **ऍप चालवण्याचे पर्याय**:
   - **वेब ब्राऊझरवर पाहण्यासाठी**: कीबोर्डवर `w` दाबा (किंवा `npm run web` चालवा). ऍप ब्राऊझरमध्ये त्वरित सुरू होईल.
   - **अँड्रॉइड मोबाईलवर चालवण्यासाठी**:
     1. मोबाईलमध्ये गुगल प्ले स्टोअरवरून **Expo Go** ऍप इन्स्टॉल करा.
     2. मोबाईल आणि लॅपटॉप एकाच वायफाय (Wi-Fi) नेटवर्कशी जोडा.
     3. टर्मिनलमधील QR कोड Expo Go ऍपने स्कॅन करा.
     4. मोबाईलमध्ये ऍपच्या "सेटिंग्ज" टॅबमध्ये जाऊन लॅपटॉपचा IP टाका (उदा. `http://192.168.1.15:5000`).

## 📡 REST API एंडपॉईंट्स (API Endpoints)

| पद्धत (Method) | एंडपॉईंट | वर्णन |
| :--- | :--- | :--- |
| `GET` | `/api/dashboard` | आजची विक्री, चालू महिना विक्री, एकूण बिले व व्हेंडर्स |
| `GET` | `/api/vendors` | सर्व नोंदणीकृत व्हेंडर्सची यादी |
| `POST` | `/api/vendors` | नवीन व्हेंडरची नोंदणी |
| `PUT` | `/api/vendors/{id}` | व्हेंडरच्या माहितीमध्ये बदल करणे |
| `DELETE`| `/api/vendors/{id}` | व्हेंडर डेटाबेसमधून हटवणे |
| `GET` | `/api/bills` | बिलांची यादी (शोध सुविधेसह: `?search=...`) |
| `POST` | `/api/bills` | नवीन भाजीपाला बिल तयार करणे |
| `GET` | `/api/bills/{id}` | विशिष्ट बिलाचा संपूर्ण तपशील |
| `DELETE`| `/api/bills/{id}` | बिल हटवणे |
| `GET` | `/api/bills/{id}/pdf` | **अस्सल मराठी PDF बिल डाउनलोड किंवा पाहणे** |
| `GET` | `/api/bills/{id}/whatsapp-link` | **मराठी WhatsApp शेअरिंग लिंक व मजकूर** |
| `GET` | `/api/settings` | व्यापारी व दुकानाचा तपशील |
| `PUT` | `/api/settings` | दुकानाचा पत्ता, नाव, नियम किंवा UPI आयडी बदलणे |

## 🗄️ SQL डेटाबेस रचना (Database Schema)

डेटाबेस `backend/billing_app.db` (SQLite) मध्ये आपोआप तयार होतो. आपण PostgreSQL किंवा MySQL वापरण्यासाठी फक्त पर्यावरण चल (Environment Variable) देऊ शकता:
`DATABASE_URL=postgresql://user:password@localhost:5432/billing_db`

### मुख्य टेबल्स:
1. `vendors`: व्हेंडरचे नाव, फोन, पत्ता, शेरा, दिनांक.
2. `bills`: बिल क्रमांक, ग्राहक नाव, ग्राहक फोन, बिल दिनांक, देयक प्रकार (रोख/उधारी), एकूण रक्कम, हमाली/वाहतूक, सूट, अंतिम देय रक्कम.
3. `bill_items`: बिल आयडी, व्हेंडर आयडी (फॉरेन की), भाजीचे नाव, एकक, प्रमाण, दर, रक्कम.
4. `shop_settings`: दुकानाचे नाव, मालकाचे नाव, फोन, पत्ता, घोषवाक्य, UPI आयडी, नियम व अटी.

## 🧪 स्वयंचलित चाचणी (Automated Testing)

बॅकएंड सर्व्हर सुरू असताना खालील कमांड देऊन संपूर्ण सिस्टीमची एकात्मिक चाचणी करू शकता:
```bash
python backend/test_integration.py
```
ही स्क्रिप्ट आपोआप:
- व्हेंडर्स तपासते.
- नवीन व्हेंडर तयार करते.
- दोन वेगवेगळ्या व्हेंडर्सच्या भाज्या असलेले बिल बनवते.
- अस्सल मराठी PDF बिल तयार करून तिची वैधता (`%PDF`) तपासते.
- WhatsApp लिंक तयार करते.
- डॅशबोर्ड आकडेवारी पडताळते.

## 👨‍🌾 भाजीपाला घाऊक व्यापाऱ्यांसाठी खास फायदे
- एकाच बिलात **शेतकऱ्यांनुसार मालाची वर्गवारी** करता येते.

- इंटरनेट किंवा स्थानिक वायफायवर अत्यंत जलद गतीने काम करते.
